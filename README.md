# Paradise Nursery Shopping Application

Paradise Nursery is an e-commerce web application designed to bring green plants and serenity straight to your doorstep. Built using React and Redux Toolkit.

## Features
- Interactive landing page with background visuals and a "Get Started" call to action.
- Category-wise plant catalog showcasing air purifiers, aromatic plants, and more.
- Dynamic shopping cart supporting item additions, quantity management, dynamic subtotals, and deletions.
- Global state management using Redux Toolkit.
